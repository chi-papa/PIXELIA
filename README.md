PIXELIAPIXELIA は、サムネイル・バナー制作に特化した軽量・高速なブラウザベースのグラフィックデザインツールです。
外部フレームワークや重厚なビルドツールを一切使用せず、純粋な HTML / CSS / JavaScript（HTML5 Canvas）と マイクロカーネル＋プラグインアーキテクチャ で構築されています。主な特徴軽快なマイクロカーネル設計
コアエンジン（js/core.js）を最小限に保ち、すべての描画ツールやUIパネルを独立したプラグイン（js/plugins/*.js）として分離。機能の追加・保守が容易です。プロ仕様の3ペインUI
長時間の制作でも目が疲れにくいダークテーマを採用。左ツールバー、上部コンテキストバー、右ドックパネル（プロパティ・整列・パレット・色調補正・レイヤー）の直感的なレイアウトで素早く作業できます。制作に直結する実用機能ホーム（スタート画面）＆自動保存: 起動時にキャンバスサイズプリセット（YouTube / SNS正方形 / X / 縦長）を選択可能。作業履歴のサムネイル付き保存や、2分ごとの自動保存（オートセーブ）による復元に対応しています。厳選 Google Fonts 対応: 商用利用可能な厳選12書体（ゴシック、明朝、丸ゴシック、極太見出し、手書き風、欧文など）を動的ロードし、キャンバス上で即座に切り替えられます。パス・矢印・多角形ツール: クリックでの頂点配置（Shift キーで45度スナップ）、角丸（スムーズ化）、終点矢印、破線、閉じた多角形の塗りつぶしに対応しています。図形・画像・色調補正: 図形の塗りなし（透明化）・不透明度調整、画像の明るさ・コントラスト・彩度補正、ブランドカラーパレットを備えています。完全クライアントサイド動作
サーバーサイド処理やデータベースは不要で、GitHub Pages などの静的ホスティングやローカル環境でそのまま動作します。ディレクトリ構成PIXELIA/
├── index.html              # アプリケーション本体（プラグイン読み込み管理）
├── pixelia_B_pixel.mp4     # スタート画面用ロゴアニメーション（※任意配置）
├── css/
│   └── style.css           # ダークテーマ・3ペインレイアウトスタイル
└── js/
    ├── core.js             # マイクロカーネル（状態管理・描画ループ・履歴・選択制御）
    └── plugins/            # 機能別プラグイン群
        ├── image.js        # 画像レイヤー配置・リサイズ
        ├── text.js         # テキストレイヤー・Google Fonts 動的ロード
        ├── shape.js        # 図形・帯レイヤー（塗りなし・不透明度対応）
        ├── path.js         # パス・矢印・多角形描画ツール
        ├── badge.js        # バッジ・装飾パーツ
        ├── align.js        # 整列・配置ガイド
        ├── canvas.js       # アートボードサイズ・背景設定
        ├── palette.js      # ブランドカラーパレット
        ├── adjust.js       # 画像の色調補正（明るさ・コントラスト・彩度）
        ├── io.js           # プロジェクトJSON保存・読み込み / 画像書き出し
        └── home.js         # スタート画面・最近のプロジェクト履歴・自動保存
